# Aula 01 — SQL com agente
Objetivo: compreender SELECT, WHERE, ORDER BY e LIMIT.
1. Abra o projeto no VS Code e leia AGENTS.md.
2. Solicite ao Codex explicacao do esquema da oficina.
3. Escreva por conta propria SELECT de clientes ordenados pelo nome.
4. Peça ao agente dicas, nao a resposta completa.
5. Entregue SQL, resultado esperado, resultado obtido e breve reflexao.
